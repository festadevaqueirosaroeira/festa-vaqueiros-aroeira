SITE — XXIII FESTA DE VAQUEIROS E FAZENDEIROS — AROEIRA

Esta pasta contém uma reconstrução completa da página para ficar visualmente muito mais próxima do protótipo western enviado na conversa.

Arquivos:
- index.html — estrutura completa e responsiva
- styles.css — identidade visual, placas de couro, cobre, papel, corda e responsividade
- script.js — menu, contagem regressiva, perfis, seleção de apoio e modais
- assets/ — recortes visuais derivados do protótipo enviado na conversa, incluindo os retratos das cinco representantes e imagens de notícias/vídeo/patrocinadores.

Para publicar no GitHub Pages:
1. Descompacte tudo.
2. Substitua os arquivos da raiz do repositório pelos arquivos desta pasta.
3. Mantenha a pasta assets no mesmo nível do index.html.
4. Faça commit/push para a branch publicada pelo GitHub Pages.

Observação: a área de voto é apenas interface visual; pagamento real/Pix e confirmação de voto ainda precisam de backend seguro e integração de pagamento.
