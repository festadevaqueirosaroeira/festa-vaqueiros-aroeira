Para testar sem GPS, digite coordenadas dentro do mapa (ex.: −11.958, −39.57).

O que este teste faz

  • Desenha uma amostra das estradas locais a partir de dados OpenStreetMap baixados para este protótipo.
  • Tenta localizar seu aparelho e traçar uma rota local até a Praça quando estiver dentro do trecho mapeado.
  • Permite guardar a página e os dados no aparelho para reabrir sem conexão, após o carregamento inicial.
Limites do protótipo

Esta amostra cobre apenas a área próxima à praça; não calcula todo o caminho desde outra cidade. Não mostra instruções curva a curva nem trânsito. Os caminhos de terra podem estar incompletos ou desatualizados. Faça o teste primeiro com internet e compare no local antes de confiar na navegação.
