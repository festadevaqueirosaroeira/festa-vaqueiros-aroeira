Protótipo autônomo de mapa offline para a Festa de Vaqueiros e Fazendeiros do Povoado de Aroeira. Dados de vias extraídos do OpenStreetMap pela API /api/0.6/map em 24/10/2026, bbox -39.59,-11.985,-39.53,-11.93. Dados © OpenStreetMap contributors, disponíveis sob ODbL. A amostra é apenas local e demonstrativa; não usar como navegação certificada nem como confirmação do acesso definitivo à festa. O roteamento é Dijkstra sobre segmentos públicos existentes no recorte.
